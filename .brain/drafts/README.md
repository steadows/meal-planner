# `.brain/drafts/` — hand-offs other lanes need to read

At `/wrap` (Phase 1 step 4), a lane moves anything in its worktree's `.context/` that another lane or @pm must read
(a hand-off, a design draft, a review brief) here, as `<lane>-<topic>-<YYYY-MM-DD>.md`. Scratch that only the lane
reads stays in its own `.context/`.

Mark a finished file `DONE <date>` on line 1. Never delete one.
